# Olga Vaschuk

Personal portfolio for Olga (Peydan) Vaschuk. Static HTML and CSS, deployed to a separate Firebase Hosting site, `olga-vaschuk`, in the existing `vaschuk-com` Firebase project.

Intended custom domain: https://olga.vaschuk.com

## Preview

Serve `public/` using any static HTTP server. No build or JavaScript dependencies are required.

## Deploy

```sh
firebase deploy --only hosting --project vaschuk-com
```

The explicit site ID in `firebase.json` keeps this deployment separate from the primary vaschuk.com site.
